# Bongure Client

**Bongure Client** is a fork of **Rushie Client (https://github.com/Rushie-Client/RushieClient-ddnet/)** with a my functions.

## Installation

For installation **Bongure Client** download a `tar.gz` file from **(https://github.com/Cser228/BongureClient/Releases)** and unarchive his.

## Build

If you on linux, you need to delete folder "build" (if she is exists), and run two commands:
```bash
cmake -Bbuild -GNinja
cmake --build build
```

## Features

* **Rushie Client**: full
* **My functions**: chat command /unfinishsay, voice assistent bonga, auto mute function, auto translate function, chat command /translate, dummy pointer, smile system.
