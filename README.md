# Bongure Client

**Bongure Client** is a fork of **Tater Client (https://github.com/TaterClient/TClient)**, with base function - voice assistent `Bonga` (STT).

## Installation

If you in Linux, for installation **Bongure Client** download a `.tar.gz` file. If you in Windows, for installation **Bongure Client** download a `.zip` file. These files you can download from **(https://github.com/Cser228/BongureClient/Releases)**

## Build

If you on linux, you need to delete folder "build" (if it exists) first. Next, if u want to compile `ELF64` u need to run this command in the terminal `make linux`, if u want to compile `.exe` u need to run this command in the terminal `make windows`.

## Features

* **Tater Client**: full
* **Bongure Client**: chat command /unfinishsay, voice assistent `Bonga`, auto mute function, auto translate function, chat command /translate, dummy pointer, smile system, custom aspect ratio (Best Client), eye comfort (Best Client), optimization things (disable textures and etc.), fast inputs (Best Client), edge info (RClient), dummy tracker (RClient), advanced dummy actions (RClient).
